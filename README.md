# О!дин запрос — Хакатон Островка 2026

Интеллектуальный сервис пакетного подбора туров под ключ («Отель + Авиаперелет + Трансфер») на все 7 Канарских островов (Тенерифе, Гран-Канария, Лансароте, Фуэртевентура, Ла-Пальма, Ла-Гомера, Эль-Йерро).

---

## 🎥 Видео-демонстрация работы сервиса

- **Ссылка на видео:** [Смотреть демонстрацию на Google Диске](https://drive.google.com/file/d/1epc-jEabfuGjjcx0SGWUPdrq2eiUYeTR/view?usp=sharing)
- В видео показан полный пользовательский сценарий: естественный диалог на русском языке, интерактивный онбординг (квизы по острову, количеству гостей, отелям и датам вылета), динамическая стыковка перелета и трансфера, моментальный расчет стоимости и оформление бронирования.

---

## 1. Стек технологий

- **Backend:** Python 3.11+, FastAPI, SQLModel / SQLAlchemy, PostgreSQL, httpx, Uvicorn.
- **Frontend:** Нативный чистый JavaScript, HTML5, CSS3 (без сторонних тяжелых фреймворков).
- **База данных и каталоги:** 
  - 19 689 отелей с координатами, рейтингами, звездностью и ценами (`data/hotels.json`).
  - 64 регулярных и стыковочных рейса (`data/flights.json`).
  - Трансферы всех типов (шаттлы, индивидуальные седаны, минивэны) (`data/transfers.json`).
- **LLM Провайдеры:**
  - **Основной провайдер:** Сбер GigaChat API (`GIGACHAT_API_PERS`).
  - **Резервный фоллбек:** Groq API (`openai/gpt-oss-20b`, `openai/gpt-oss-120b`).

## 2. Быстрый запуск

### Вариант 1: Запуск через `uv` (рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd odin_zapros_canary
   ```

2. Установите зависимости проекта:
   ```bash
   uv sync
   ```

3. Расшифруйте секреты для жюри (с помощью утилиты `age`):
   ```bash
   age -d -i <ВАШ_ПРИВАТНЫЙ_КЛЮЧ> secrets.env.age > .env
   ```
   *(Или заполните файл `.env` на основе примера `.env.example`).*

4. Запустите сервис:
   ```bash
   uv run uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload
   ```

5. Откройте интерфейс в браузере:
   ```
   http://127.0.0.1:8080
   ```

---

### Вариант 2: Запуск через Docker Compose

```bash
docker compose up --build
```
Интерфейс будет доступен по адресу `http://localhost:8080`.

## 3. Секреты и переменные окружения

- `secrets.env.age` — зашифрованные ключи для организаторов и жюри (зашифровано публичным ключом `age1932fu7f70rwyfhaxflyfszz4gf6avxwc95wc0yjwm6zns9tspycqpgdnc0`).
- `.env.example` — шаблон конфигурации со списком необходимых переменных.
- Открытый файл `.env` исключен из системы контроля версий через `.gitignore`.

---

## 4. Ключевые возможности

1. **Комплексная сборка тура («О!дин запрос»):** Агент состыковывает отель, прямой или стыковочный рейс и трансфер из аэропорта прилета прямо до дверей выбранного отеля.
2. **Динамический пересчет и синхронизация:** Изменение дат вылета, количества ночей или гостей в чате мгновенно пересчитывает календарную сетку («18 — 28 ноября 2026») и финальную стоимость тура.
3. **Интерактивные сценарии (Show Quiz):** При нехватке параметров или сомнениях пользователя агент генерирует интерактивные кнопки быстрого выбора (острова, длительность, формат отелей).
4. **Отказоустойчивость и Guardrails:** Встроенная защита от оффтопа, провокаций, инъекций и каскадное переключение моделей при исчерпании квот.
